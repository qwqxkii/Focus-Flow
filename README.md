# 关于 Focus Flow

Focus Flow 是一个现代化的任务管理和时间追踪应用，旨在帮助用户提高工作效率和时间管理能力。

## 特色

- 🚀 纯前端实现，无需后端服务
- 💾 数据本地存储，保护隐私
- 🌓 支持深色模式
- 📱 响应式设计，支持移动端

## 核心功能

- **任务管理**：直观的待办事项管理，支持拖拽排序和标签分类
![](/img/代办事项页面1.jpeg)
- **番茄时钟**：科学的时间管理工具，帮助您保持专注
![](/img/代办事项页面1.jpeg)
- **数据统计**：可视化的工作统计，追踪您的生产力表现
![](/img/番茄时钟统计1.jpeg)
- **标签系统**：灵活的任务分类，让工作井然有序
![](/img/标签管理页面1.jpeg)

## 技术栈

- **框架**：Vue 3 + Vite
- **UI库**：Naive UI
- **状态管理**：Vue Composition API + VueUse
- **数据存储**：LocalStorage
- **图表**：ECharts
- **拖拽**：Vue Draggable
